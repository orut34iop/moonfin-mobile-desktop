源码依据：`/Volumes/mba2t/projects/moonfin-mobile-desktop/lib/ui/navigation/app_router.dart`、`/Volumes/mba2t/projects/moonfin-mobile-desktop/lib/ui/navigation/destinations.dart`、`/Volumes/mba2t/projects/moonfin-mobile-desktop/lib/ui/widgets/navigation_layout.dart`、`/Volumes/mba2t/projects/moonfin-mobile-desktop/lib/ui/widgets/left_sidebar.dart`、`/Volumes/mba2t/projects/moonfin-mobile-desktop/lib/ui/widgets/top_toolbar.dart`、`/Volumes/mba2t/projects/moonfin-mobile-desktop/lib/ui/widgets/user_menu_dialog.dart`、`/Volumes/mba2t/projects/moonfin-mobile-desktop/lib/ui/screens/admin/widgets/admin_drawer.dart`、`/Volumes/mba2t/projects/moonfin-mobile-desktop/lib/ui/screens/settings/settings_side_panel.dart`、`/Volumes/mba2t/projects/moonfin-mobile-desktop/lib/ui/screens/livetv/live_tv_screen.dart`。

说明：
- `Route Path` 为 `GoRouter` 绑定路径；`N/A` 表示该入口是弹窗、外链、覆盖层，或 `SettingsPanel.pushSettingsScreen` 内部堆栈，不走 `GoRouter`。
- `Menu Name` 优先使用源码中的本地化 key，并补充英文/中文含义；动态库入口使用 `${lib.name}`。
- `Page Component` 为绑定到该入口的顶层页面组件所在绝对路径；设置面板内的私有页面类均位于 `settings_side_panel.dart`。
- `/library-view/:libraryId` 只在 `Destinations` 中声明，未在 `app_router.dart` 绑定 `GoRoute`，因此不列为可达路由。
